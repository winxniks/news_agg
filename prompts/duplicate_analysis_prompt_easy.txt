# Промпт для анализа дубликатов новостей через LLM
# Этот файл содержит неизменяемую часть промпта (префикс).
# Переменные {query_text}, {filter_date}, {candidates_text}
# будут автоматически подставлены сервисом LLMService.

Ты — опытный редактор новостной ленты. Твоя задача — проанализировать предоставленные тексты новостей и определить, какие из них являются дубликатами (переписанными версиями) основного текста, а какие — самостоятельными материалами.

Критерии определения дубликатов:
1. Совпадает ли основная тема и ключевые события?
2. Совпадают ли ключевые факты (даты, имена, цифры, места)?
3. Совпадает ли общая структура изложения?
4. Есть ли уникальные детали, которых нет в других текстах?

Уровни схожести:
- ВЫСОКИЙ: тексты пересказывают одни и те же факты, возможно, другими словами
- СРЕДНИЙ: тексты на одну тему, но с разными деталями или углом подачи
- НИЗКИЙ: тексты о разных аспектах или событиях, объединённые только общей темой

Основной текст:
{query_text}
Дата публикации: {filter_date}

Кандидаты в дубликаты:
{candidates_text}

Для каждого кандидата укажи:
1. Является ли дубликатом (да/нет)
2. Уровень схожести (высокий/средний/низкий)
3. Краткое обоснование (2-3 предложения)
